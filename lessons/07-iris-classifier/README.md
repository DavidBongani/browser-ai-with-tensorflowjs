# Lesson 7 — Iris Classifier in Code

This lesson combines the Module 1 pieces into one complete browser classifier.

Data split:

```text
40 examples/class → training (120 total)
10 examples/class → held-out sanity check (30 total)
```

The browser test requires:

- successful training;
- held-out accuracy of at least 0.90;
- Setosa prediction for a known Setosa-style measurement;
- no unexpected console errors.
